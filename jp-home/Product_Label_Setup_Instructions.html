How to Setup Product Labels in Theme

This guide will walk you through setting up product labels in your Shopify theme. Product labels display icons and text on product cards and product pages based on metafield values.

⚠️ Important: Filename Convention
When uploading label images, you must use a specific filename format. Remove all special characters except hyphens (-), convert to lowercase, and use only letters, numbers, and hyphens. The filename must match the label text converted to a handle format.

Prerequisites

  1. Product metafield definitions must be created in Shopify Admin (this is where you get the namespace.key)
  2. Theme settings must be configured to reference the metafields
  3. Label images must be uploaded with correct filenames

Step 1: Create Metafield Definitions

💡 Important: This is where you get the namespace.key that you'll use in the theme settings. The namespace and key are automatically generated when you create the metafield definition, and you'll need this exact format to configure the theme later.
1 Navigate to Metafields and metaobjects
  • Go to Settings → Metafields and metaobjects → Products
  • Click "Add definition"
2 Create Metafield Definition
  • Name: "Product Icon #1 Label" (or #2, #3, #4, #5)
  • Namespace and key: This will be automatically set to custom.product_icon_label_1 (or custom.product_icon_label_2, etc.)
  • 📝 Note: The format custom.product_icon_label_1 is your namespace.key - you'll need this exact value for theme settings configuration!
  • Type: Select "Single line text" (make sure this is selected)
3 Configure Validation Settings
  • Under the "Validation" section, make sure "Unique values" is unchecked
  • This allows multiple products to use the same label values (e.g., multiple products can have "Glutten-free")
  • Review all options to ensure they are configured correctly
Figure 2: Validation Settings - Ensure Unique values is unchecked
Figure 3: Review All Options - Final Configuration
4 Copy the Namespace.Key and Save
  • After creating the metafield definition, you'll see the Namespace and key displayed
  • For Product Icon #1 Label, it will be: custom.product_icon_label_1
  • Save this value - you'll need it in the next step for theme configuration!
  • Click "Save" to save the metafield definition
  • Repeat for all 5 labels (#1 through #5)

Step 2: Configure Metafields in Theme Settings

💡 Note: Now that you've created the metafield definitions, you'll use the namespace.key format (e.g., custom.product_icon_label_1) that you copied from Step 1. The format is just namespace.key without the product.metafields. prefix.
1 Navigate to Theme Customizer
  • Go to Online Store → Themes
  • Click "Edit Theme" on your active theme
2 Access Theme Settings
  • Click the "Theme settings" button (usually at the bottom of the left sidebar)
  • Scroll down to find the "Product card" section
  • Look for "Product icons" section
Figure 6: Entering namespace.key in Icon Label Field
3 Configure Product Icon Labels

For each product icon (Icon 1, Icon 2, Icon 3, Icon 4, Icon 5), you'll see two fields:

  • Icon Image: Leave blank (images are auto-loaded based on label)
  • Icon Label: Enter the namespace.key from Step 1 in format: custom.product_icon_label_X

Example values (use the namespace.key you got from creating metafield definitions in Step 1):

  • Icon 1 Label: custom.product_icon_label_1
  • Icon 2 Label: custom.product_icon_label_2
  • Icon 3 Label: custom.product_icon_label_3
  • Icon 4 Label: custom.product_icon_label_4
  • Icon 5 Label: custom.product_icon_label_5
Figure 7: All Product Icons Configured

Step 3: Upload Label Images

⚠️ Critical: Filename Format Requirements
  • Remove all special characters except hyphens (-)
  • Convert to lowercase
  • Spaces become hyphens
  • Apostrophes, quotes, and other special characters are removed
  • File extension must be .png
1 Prepare Your Images
  • Create your label icons (recommended size: 32x32px to 144x144px)
  • Save as PNG files
  • Rename files according to the filename convention (see examples below)
2 Upload to Shopify Files
  • Go to Content → Files
  • Click "Upload files"
  • Upload your label image files
Figure 4: Upload Label Images to Content → Files

💡 How it Works: The theme automatically converts your label text (e.g., "Glutten-free") to a handle format (e.g., "glutten-free") and looks for a matching image file in your Content → Files. If found, it displays the image alongside the label text.

Step 4: Add Label Values to Products

1 Edit a Product
  • Go to Products in Shopify Admin
  • Click on a product to edit
  • Scroll down to the "Product metafields" section (or "Pinned" section if metafields are pinned)
2 Enter Label Values
  • Find the metafield fields: "Product Icon #1 Label", "Product Icon #2 Label", etc.
  • Enter the label text exactly as you want it to appear (e.g., "Glutten-free", "Vegan")
  • Important: The text must match your image filename format (see Step 3)
Figure 3: Product Edit Page - Entering Metafield Values
3 Save the Product
  • Click "Save"
  • The labels will now appear on product cards and product pages

Step 5: Bulk Import via CSV

To import label values for multiple products at once:

1 Prepare Your CSV
  • Create a CSV file with columns: Handle, Title, and metafield columns
  • Metafield column format: product.metafields.custom.product_icon_label_1
  • Enter label values in the corresponding rows
2 Import Products
  • Go to Products → Click "Import"
  • Upload your CSV file
  • Review the preview and click "Import products"
Figure 8: CSV Import Interface
📝 CSV Column Format:
  • Column header: product.metafields.custom.product_icon_label_1
  • Value: The label text (e.g., "Glutten-free", "Vegan")

Final Result - Preview

✅ Success! If all the steps above have been correctly followed, your product labels should now be displayed on your products. The labels will appear with their corresponding icons (if images were uploaded) and will be filterable in collection pages.
Product Labels Display

Product labels will appear on:

  • Product Cards - Labels are shown on product listing pages (collections, search results, etc.)
  • Product Pages - Labels appear on individual product detail pages

Troubleshooting

Images Not Showing?

  • ✓ Check that the filename matches exactly (case-sensitive, lowercase)
  • ✓ Verify the image is uploaded to Content → Files
  • ✓ Ensure the filename uses hyphens, not underscores or spaces
  • ✓ Confirm the file extension is .png (lowercase)

Labels Not Displaying?

  • ✓ Verify metafield definitions exist in Settings → Metafields and metaobjects → Products
  • ✓ Check theme settings have metafield references configured
  • ✓ Confirm products have metafield values entered
  • ✓ Ensure you're viewing a product page or product card where labels are enabled

Need Help? If you encounter any issues, verify that:

  1. Metafield definitions are created and pinned
  2. Theme settings reference the correct metafields
  3. Image filenames follow the exact format specified above
  4. Products have metafield values assigned
